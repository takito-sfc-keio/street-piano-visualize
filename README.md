# Street Piano Insights

ビルド不要のHTML / CSS / JavaScriptです。夕暮れの街とグランドピアノを描いた文字なしの新規素材に、実際のHTMLテキスト・操作・CSSの陰影を重ねています。元の生成画像は参照会話から取得できなかったため、指定された構図に基づく再制作です。

## 起動
このフォルダーを静的Webサーバーに配置してください。ローカル確認の例：

```sh
python3 -m http.server 8080
```

ブラウザで http://localhost:8080 を開きます。ファイルの直接ダブルクリック（file://）ではfetchが制限されるため、HTTPサーバーが必要です。

## API設定（config.js）
1. `apiUrl` をバックエンドのURLに変更します。例：`/api/today-count`
2. `demoMode` を `false` にします。
3. 想定レスポンスは `{"count":128}`。形式が変わる場合は `getCount` のみ変更します。例えば `{"data":{"total":128}}` なら `(payload) => payload.data.total`。

人数は0以上の安全な整数（数値型）を受け付けます。0人も正しく表示します。不正データ・通信エラー・8秒のタイムアウト時は「—」と再読み込みボタンを表示し、128人に戻すことはありません。初期値は同梱JSONから取得するデモです。実際のバックエンドは未接続です。ページ表示時と再読み込みボタン操作時に取得します。

別ドメインのAPIはバックエンド側でサイトのOriginをCORS許可してください。HTTPSサイトからはHTTPSのAPIを使用してください。秘密鍵はフロントエンドに置かないでください。認証仕様が確定したらapp.jsのfetchオプションを調整します。

## スポット
`config.js` の `spots` に `name`, `description`, `url` を追加できます。未設定では準備中の表示になります。架空のスポットは登録していません。ボタンとSCROLLはこのセクションに移動します。

## ファイル
- index.html：構造、コピー、ナビゲーション
- styles.css：PC・スマートフォンのレイアウト、背景位置、陰影、動きを減らす設定
- config.js：API URL、データの抽出処理、タイムアウト、スポット
- app.js：取得処理、エラーと再試行、メニュー
- demo/count.json：確認用レスポンス
- assets/dusk-piano.png：文字・UIなしの新規生成素材

日本語は端末の明朝体、英字・数字はGeorgiaを使い、外部フォントやライブラリーへの依存はありません。背景差し替えは画像ファイルの置換、スマートフォンの構図調整はstyles.cssの`.scene`の`background-position`で行えます。
